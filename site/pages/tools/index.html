Tools

Beside the design system, afrigov has tools for the work around a government website: checking it, making its images light, and running it on WordPress. Each works on its own, on any site.

Which one to use

If you want to Use How
Build new pages that are accessible and light The design system Two link tags, or npm install afrigov
Find out what is wrong with a page that already exists Audit One command, on any website
Make a folder of photographs light enough for a phone Images One command, on your own computer
Build pages in WordPress without writing code WordPress A theme and a blocks plugin

How they fit together

A ministry with an old website can start with Audit. It scores the pages, says what to fix first, and names the images that are too heavy. Images fixes those. Neither needs the site to be rebuilt.

When the site is rebuilt, the design system or the WordPress theme gives pages that pass the same audit from the start. The use cases show this on four real government websites, with the scores before and after.

All open source

Every tool is free to use, change and run yourself. The design system, Audit and Images are MIT licensed. The WordPress theme and plugin are GPL, as WordPress requires. The code is in the afrigov organisation on GitHub.
