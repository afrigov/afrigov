Back link

Above the heading on every question page. It goes to the previous step, and only there.

When to use

On every page of a form journey except the first. People make mistakes and want the step before, not the browser history.

When not to use

On content pages, where a breadcrumb says where you are. Never both.

Accessibility

  • The text is "Back". Screen reader users hear it first on the page, after the skip link and header.
  • It is a real link to the previous page's address, not a script that calls history back, so it works when the page was reached directly.
  • The chevron points into the reading direction and mirrors for right-to-left languages.
