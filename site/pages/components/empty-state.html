Empty state

What a listing shows when there is nothing to list: no events scheduled, no applications yet, no results for a search.

When to use

Any page whose main content is a list that can be empty. Say that it is empty, why if you know, and what the person can do.

When not to use

For errors or warnings. Use an alert for those.

Accessibility

  • The title is a heading, so people navigating by heading find out the list is empty.
  • Keep it in the place the list would be, so the page structure does not change when content arrives.
