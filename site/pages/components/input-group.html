Accessibility

  • The affix is aria-hidden because the unit is already in the label or hint. Say "Amount in naira", not just "Amount".
  • Use inputmode="decimal" for money so the phone keyboard has a decimal point.
  • Do not put the symbol inside the input as a value. It breaks validation and autofill.

Pack fields

currency.symbol, currency.position, currency.hint.
