Pagination

For lists too long for one page: search results, news, a table of applications.

When not to use

For steps in a form. Use Continue and Back buttons. For fewer than about 25 items, show them all.

Accessibility

  • Every link is a real URL with the page number in it, so it works without script and can be bookmarked.
  • The current page has aria-current="page" and is still a link, so its position is announced.
  • Previous and Next carry rel attributes for browsers and crawlers.
  • Show at most seven numbers; use the ellipsis for the rest.
