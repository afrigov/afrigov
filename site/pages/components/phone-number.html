Phone number

A dialling code and a national number. The code comes prefilled from the country pack, and people type the number the way they already write it.

When to use

Whenever a service will call or text someone. SMS is how most African services confirm identity and send references, so this is usually the most important field on the page.

When not to use

For a landline extension or a number that is never dialled by the service. A plain text input is enough there.

How it works

  • The question is the legend. Each control has its own visible label, like the date input.
  • Preselect the pack's dialling code. Most people entering a number live in the country the service is for.
  • Accept the national format with or without the leading zero, with or without spaces. Normalise on the server.
  • Put an example in the hint. Each pack carries one in the local style.
  • type="tel" opens the phone keypad; autocomplete="tel-national" lets the browser fill it.

Errors

Mark the fieldset with ag-field--error, put one message above the controls, and link to the number field from the error summary. Say what a valid number looks like: "Enter a phone number, like 0803 000 0000".
