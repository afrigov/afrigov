Textarea

For more than one line: a description, an explanation, anything else we should know.

Do not include personal or financial information, like your bank details

Accessibility

  • Set rows to the size of the answer you expect. Five rows is enough for most.
  • The textarea can be resized vertically but not horizontally, so it never breaks the layout.
  • If there is a length limit, say so in the hint. A live character count arrives in 0.2.
  • Errors work the same way as the text input.
