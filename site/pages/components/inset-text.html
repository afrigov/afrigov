Inset text

A callout inside content for something that applies only to some readers, or that is worth a second look.

You can apply on behalf of someone else if you have their written consent and a copy of their ID.

When not to use

For warnings or errors, use an alert. For something everyone must read, put it in the main text. Do not stack insets.

Accessibility

  • It is a plain block with a border. There is no role, so it reads as ordinary text, which is what it is.
  • Keep it to a sentence or two.
