Community

afrigov is built in the open. The most useful contributions right now are country packs and banner translations, and both are one JSON file.

Contribute

  • Contributing guide: setup, what we are looking for, the pull request checklist.
  • Good first issues: packs and translations that need a native speaker.
  • Report a bug: accessibility problems are the highest priority.
  • Discussions: questions, ideas, and showing what you built.

Translations

We only ship strings a native speaker can vouch for. A missing language is better than a wrong one. Each pack lists the languages it still needs, and every one has an open issue with the exact strings to translate.

Where it stands

Version 0.9. Three things stand between here and 1.0: a manual screen-reader pass on every component, the publication of the accessibility scoreboard of public services in the pack countries, and one real service built on afrigov by someone other than us. The changelog has what each version added, and the component registry has every component with the version it shipped in.

Decisions

The choices that are expensive to reverse, and why they were made:

  • Plain CSS with custom properties, no Sass, no framework
  • Official colours are decorative; usable colours are derived
  • No date picker, no modal, no toast, no carousel
