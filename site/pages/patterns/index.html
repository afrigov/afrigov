Patterns

A pattern is a question a service has to ask, and the tested way to ask it. Patterns are built from components and come with the research behind them.

Available now

  • Ask for a date of birth: three fields, no picker.
  • Show errors: the summary at the top, the message at the field, focus moved.
  • Ask for a phone number: dialling code from the pack, number as people write it.
  • Ask for a national ID number: shape and hint from the pack.
  • Ask for an address: region then sub-region, from the pack.
  • Show an amount of money: symbol and grouping from the pack.
