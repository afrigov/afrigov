How it works

  • Say what was searched and how many results. The count line has role="status", so a screen reader announces it when the results change without the page reloading.
  • One heading per result, linking to the page. The headings let a screen reader user move from result to result.
  • Where it sits on the site, under the title, so two results with similar titles can be told apart. For a document, its type and size.
  • The searched words are bold on a pale tint with mark, which screen readers can announce. Never colour alone.
  • Ten results a page, then pagination.
  • No results is a page that helps, using the empty state: a spelling suggestion where the search engine gives one, a way in through the services, and a person to ask.
