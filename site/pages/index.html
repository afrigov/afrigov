Why afrigov

Most government sites on the continent fail basic accessibility checks, not for lack of care but because every ministry and contractor starts from zero. This is the starting point.

  1. No build step

    Two link tags and you are done. Plain CSS with custom properties. No Sass, no bundler, no framework.

  2. Country packs

    The core has no flag colours. A pack adds them, derives text-safe variants, and carries the official banner strings in the country's languages.

  3. Works on a 2G connection

    System fonts only, 5 KB of CSS, and every component works with JavaScript turned off.

  4. AA is enforced, not promised

    The build fails if any colour pair misses 4.5:1. axe-core runs on every page of this site, with every pack, on every pull request.
