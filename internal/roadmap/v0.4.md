# v0.4: Right-to-left and page templates

**Goal:** the two 1.0 blockers that do not depend on anyone else. Arabic is official in a third of the continent, and agencies copy pages, not components.

## Scope

### Right-to-left

- Core CSS converted to logical properties; explicit mirroring for the chevrons, the start arrow and the select caret.
- A build test that rejects physical layout properties in the core.
- Morocco pack with `direction: "rtl"`. The docs mirror every example when a right-to-left pack is previewed, and the axe suite runs the mirrored pages.

### Page templates

Full pages an agency can copy, each a complete HTML file in the docs, tested with axe as a page:

- Start page
- Question page (one thing per page)
- Check your answers
- Confirmation
- Error page (there is a problem with the service)
- Service home with cards

## Exit criteria

- [ ] No physical layout properties in `core.css`; the test enforces it.
- [ ] Morocco previews with every example mirrored and the axe suite green in that mode.
- [ ] Six templates on the docs site, each passing axe and the touch-target check at phone width.
