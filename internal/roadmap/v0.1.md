# v0.1: First public release

**Goal:** a complete, honest, small system that one agency could use to build one service end to end, and that proves the pack model with two countries.

**Shipped 2026-09-30.**

## Scope

- Core: reset, base, tokens, layout, focus ring.
- 15 component files covering page furniture, actions, forms, feedback.
- Packs: Nigeria, Kenya.
- Token pipeline with contrast gate and derivation.
- Optional JS: nav toggle, error summary focus.
- Docs site with every component, pack switcher, diacritics test.
- Tests: unit, axe, touch targets, size budget.
- CI, release, Pages workflows. Issue templates for bugs, accessibility, packs.

## Exit criteria

- [x] `pnpm check` and `pnpm test:a11y` green.
- [x] `core.min.css` under 20 KB gzipped (5 KB).
- [x] Every component on the docs page with HTML shown.
- [x] Both packs pass every contrast pair.
- [x] README explains the pack model in under a screen.
- [ ] Published to npm as `afrigov@0.1.0`.
- [ ] Docs live at omoyolab.github.io/afrigov.

## Cut from 0.1

- Modal, toast, carousel: cut permanently (see components.md).
- Phone, ID, region inputs: moved to 0.2 so 0.1 stays country-neutral in its components and only the packs know about countries.
- Ghana pack: moved to 0.2, so 0.1 has two packs that both pass without derivation surprises. Ghana is the derivation test case.
