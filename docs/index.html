Why afrigov

No build step

Two link tags and you are done. Plain CSS with custom properties. No Sass, no bundler, no framework.

Country packs

The core has no flag colours. A pack adds them, derives text-safe variants, and carries the official banner strings in the country's languages.

Works on a 2G connection

System fonts only, 5 KB of CSS, and every component works with JavaScript turned off.

AA is enforced, not promised

The build fails if any colour pair misses 4.5:1. axe-core runs on this page, with every pack, on every pull request.

Get started

From a CDN

Add the core and one country pack. The pack must come after the core.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/afrigov@0.1/dist/core.min.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/afrigov@0.1/dist/ng.min.css">

<!-- Optional: collapsible navigation and error-summary focus. 1.5 KB. -->
<script src="https://cdn.jsdelivr.net/npm/afrigov@0.1/dist/afrigov.iife.js" defer></script>

From npm

npm install afrigov
import "afrigov/core.css";
import "afrigov/ng.css";
import { init } from "afrigov";

init();

Then write HTML

Every component is a class on a plain element. Copy the markup from the examples below. The class prefix is ag-.

Country packs

A pack is one JSON file. It declares the official national colours and which of them is the primary. The build derives everything else: a primary that passes AA as text, a hover state, tints, and link colours. The flag stripe always uses the exact official colour.

Packs in this release
Pack Official primary Usable primary Banner languages
ng.css Nigeria #008751 #007d4b derived (4.13:1 on grey was not enough) English. Hausa, Yoruba, Igbo wanted.
ke.css Kenya #006600 #006600 unchanged (7.2:1) English, Swahili (draft, native review wanted).

Want your country? Copy tokens/packs/ke.tokens.json, change the colours and strings, open a pull request. The contrast tests run for you. See adding a country pack.

Form fields

Labels are always visible. Hints and errors are tied to the control with aria-describedby. The error state marks the whole field, not just the border. Error messages start with a visually hidden "Error:" so screen readers announce it.

Error summary

When a form is submitted with errors, put this at the top of the page and reload. afrigov.js moves focus to it. Each item links to the field it describes.

  • Enter your National ID number

Language and type

afrigov uses system fonts only, so pages load with zero font requests. The stack names Noto Sans before Arial because it covers the Latin Extended ranges that many African languages need. The lines below are the test: every diacritic should render in the same weight and size as the letters around it.

Yoruba
Ẹ̀tọ́ ọmọ orílẹ̀-èdè ni láti gba ìwé ìrìnnà. Ẹ kú iṣẹ́.
Hausa
Ƙasar Najeriya ta ɗauki ɓangaren ƴan ƙasa da muhimmanci.
Igbo
Ọ bụ ikike gị ịnweta akwụkwọ ikike ije. Ndeewo.
Swahili
Huduma za serikali ni haki ya kila raia.
French
Les services publics sont accessibles à tous les citoyens.
Portuguese
Os serviços públicos são acessíveis a todos os cidadãos.
Arabic
الخدمات الحكومية حق لكل مواطن.

Set lang on the html element and on any passage in another language, so screen readers switch voice and hyphenation is correct. Use dir="rtl" for Arabic content.

Tokens

Every value is a CSS custom property prefixed --ag-. The source of truth is tokens/core.tokens.json in the W3C Design Tokens format. Swatches below show the active pack.

  • --ag-color-primary
  • --ag-color-primary-hover
  • --ag-color-primary-tint
  • --ag-color-accent
  • --ag-color-ink
  • --ag-color-ink-muted
  • --ag-color-paper-alt
  • --ag-color-border-strong
  • --ag-color-focus
  • --ag-color-success
  • --ag-color-warning
  • --ag-color-error
  • --ag-color-info

Override a token

Set the custom property after the pack. Nothing else changes.

:root {
  --ag-size-container: 60rem;
  --ag-font-family-sans: "Public Sans", system-ui, sans-serif;
}

Contribute

The most useful contributions right now are country packs and banner translations. Both are one JSON file and need no CSS knowledge. Bugs in accessibility are treated as the highest priority.
