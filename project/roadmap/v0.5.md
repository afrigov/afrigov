# v0.5: What the first rebuild was missing

**Goal:** close the gaps found by rebuilding fmcide.gov.ng (`afrigov-usecase-fmcide/FINDINGS.md`) before any more pages are built on top of workarounds.

## Scope

- Back link component (#17). The page templates and the rebuild carried it as page-local CSS.
- Dated list (#18): news, events, articles, documents.
- Image and figure (#19), with a gallery grid and the rules for alt text, captions, file size and loading.
- Download link with format and size (#20).
- Empty state (#21).
- Hero with an optional image beside the text. A ministry site needs the minister's photograph somewhere; the component decides where, and keeps text off the photo.

## Exit criteria

- All six on the docs with axe passing for every pack, in the registry, and used by the page templates where they apply.
- The rebuild regenerated with no page-local CSS left, every page still A.
- Issues #17 to #21 closed from the release.
